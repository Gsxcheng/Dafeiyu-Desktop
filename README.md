# 大肥鱼 Desktop | Dafeiyu-Desktop

> **从桌面出发，让同一个 AI 伙伴陪你走向更多聊天场景。**
>
> **项目状态：产品规划阶段 / 需求与视觉规范草案** · 更新：2026-11-04 · 尚未发布可运行版本

**大肥鱼 Desktop**（项目与桌面客户端名称，GitHub 仓库 `Gsxcheng/Dafeiyu-Desktop`）是一个计划开源、支持多角色、跨渠道与跨设备连续对话的 **AI 情感陪伴与 Agent 平台**。

从 QQ 群里的「大肥鱼」出发，希望以后能在 **Desktop、Web、手机 App**，以及技术与平台规则允许的 **QQ、微信等聊天渠道**，和同一个 AI 角色持续交流。角色、记忆、会话、提醒、插件属于平台层，不属于某个 QQ Bot 或第三方客户端。

> ⚠️ **这个仓库现在是需求和设计资料，不是已经可安装的产品。** 截图、交互与功能若未真实验收不得标成已实现。

## 我们想打造的体验

- **陪伴与互动**：有鲜明人格的角色，擅长自然对话、主动但不过度打扰，支持后续表情、图片和语音。
- **人格广场**：发现、创建、预览与分享角色卡；用户可控制角色设定和记忆边界。
- **跨端连续聊天**：在 Desktop 与手机 App、经授权绑定的消息渠道之间续聊；群聊和私聊的隐私空间独立。
- **长期记忆**：区分短期上下文、个人记忆、群记忆与工作记忆；可查看、纠错、导出和删除。
- **任务与 Agent**：提醒、待办、总结；管理员私聊和指定工作群可调用经授权的工作能力。
- **开放插件**：优先复用成熟插件 SDK，未来面向社区提供插件开发、发现、安装与安全审查机制。
- **鲸鱼娘桌宠**：未来让角色以桌面小窗或 Live2D/帧动画出现，点击打开聊天、到点提醒、展示工作状态；可关闭。

## 第一位角色：大肥鱼

「大肥鱼」是首个示范人格：**蓝色鲸鱼娘、轻松游戏群友风格**。她来自现有的 QQ-BOT 实验，不等于平台全部角色。未来用户可以替换大肥鱼为自己的原创角色，并为不同角色安装不同技能。

**形象定位：** 清亮的海蓝色系、鲸鱼元素、圆润但不过分幼态的桌面陪伴视觉。角色立绘、Q版动效、Logo 必须使用有明确权利的原创或许可素材；不直接把 DeepSeek 官方 Logo 或社区二创素材当成可商用素材。

## 推荐的产品结构（非已实现）

```text
大肥鱼 Desktop / Web / 未来手机 App / QQ / 微信等渠道
                       │
                 接入与身份绑定
                       │
              统一角色与会话核心
          ┌────────────┼────────────┐
       人格与记忆     任务与 Agent    插件与权限
          └────────────┼────────────┘
               模型 API / 持久化
```

QQ-BOT 是第一个验证场景，后期核心服务应独立于 QQ、SnowLuma、NapCat 或 AstrBot 的内部数据结构。具体引擎选型仍待实测。

## 和已有 QQ-BOT 的关系

- **Dafeiyu-Desktop**：新产品的统一 Desktop 入口与开源项目仓库；核心架构面向多端共享，不与 QQ 或 Desktop 进程绑定。
- **QQ-BOT / 大肥鱼**：已有实验项目与示范角色，历史运维状态仍在私有 `GSX_Knowledge` 的 `QQ-BOT` 项目中维护。

本公开仓库**不得导入**原 QQ 登录态、QQ 号、群聊原文、API Key、Token、Cookie、私有项目文档或敏感截图。
