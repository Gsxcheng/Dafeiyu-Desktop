# Roadmap｜阶段里程碑（建议稿）

- 状态：PROPOSED
- 原则：先验证最小闭环，再建设跨端平台；版本代表里程碑，不承诺日期。

## Phase 0：需求与技术验证
**交付：** 需求基线、关键风险表、实验环境和第三方许可证清单。

通过条件：范围可追溯，历史 QQ-BOT 仅引用已公开的非敏感背景；已确认需求与技术假设分开。

## V0.1：大肥鱼单渠道验证
Windows 本机、QQ + 候选协议端 + AstrBot，验证基础人格、提醒、待办、最低限度记忆、插件安装和权限隔离。

**通过条件：** 10 轮无重复消息，提醒真实送达、可取消、重启数据未丢失、插件启停正常、普通群越权工具调用拒绝。

**不包含：** 在线人格广场、真正多渠道同步、手机 App、第三方插件沙箱、云端多租户。

## V0.2：统一角色与数据服务
统一账号、角色、会话、记忆、任务 schema/API，渠道与 Agent 引擎逐步解耦。

通过条件：不同角色记忆互不污染，用户可以删除/导出记忆，切换接入不丢失角色本体。

## V0.3：集中式 Desktop
单窗口管理机器人、人格、插件、模型、提醒、日志、诊断；提供配置和托盘入口。

通过条件：非开发者在无需命令行的情况下完成核心功能，插件设置和角色配置持久化。

## V0.4：跨端账号 + Web
统一身份、Desktop 与 Web 续聊、私聊历史同步、设备管理。

通过条件：同一用户在两个受信任客户端恢复同一角色的对话，群数据不泄露。

## V0.5：第二消息平台
选择稳定且许可范围明确的第二渠道适配器，不预设必须是个人微信号。

通过条件：同角色在两个渠道可用，身份绑定可撤销，发送状态和权限可观测。

## V0.6：手机 App 原型
提供聊天、角色、历史、提醒通知和登录；iOS/Android 方案待选。

通过条件：手机独立访问统一核心；若采用远端核心，关闭 Desktop 不影响后台任务。

## V0.7：鲸鱼娘桌宠
透明桌宠窗、原创 Q 版动画、低占用、可关闭、与聊天和提醒同步；Live2D 待验证。

通过条件：桌宠点击打开正确会话，真实任务驱动提醒，关闭桌宠不影响服务，不擅自读取屏幕/麦克风。

## V0.8：人格和插件生态
角色卡格式、人格广场、插件市场、开发者模板、兼容性、审核与举报。

通过条件：第三方无需改核心即可发布、更新扩展，权限和风险清楚展示。

## V1.0：开源产品交付
安装包、升级迁移、备份恢复、稳定性、权限、隐私、安全与用户文档。

通过条件：支持矩阵有实际验收记录，开源仓库无敏感数据，软件许可证与 IP 素材权属确认。

## 优先级
- P0：聊天闭环、人格、提醒、待办、持久化、插件兼容和权限。
- P1：数据解耦、Desktop、跨端身份、第二渠道。
- P2：App、桌宠、社区广场、插件开发者生态。

主路径可能因 QQ/微信非官方接入风险调整，平台核心不能依赖任何一个可能受限的适配器。
