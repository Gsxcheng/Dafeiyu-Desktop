## 命名与产品边界

`Dafeiyu-Desktop` 是首个开源 Desktop 产品和 GitHub 仓库的名称，不代表只支持桌面。用户、角色、会话、个人/群记忆、任务、插件和权限应按跨端服务设计；QQ、微信、Web 和未来手机 App 是不同客户端或渠道适配层。

首位示范角色为鲸鱼娘「大肥鱼」；人格广场应允许社区作者发布其他角色。不得把 DeepSeek 商标或特定第三方 IP 写死为平台通用能力。
