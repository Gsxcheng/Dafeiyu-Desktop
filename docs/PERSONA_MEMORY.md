# 人格广场与长期记忆规范（草案）

- 状态：PROPOSED
- 目标：人格可分享；用户掌握记忆；跨端一致而不跨群泄漏。

## 1. 人格卡最小结构

```yaml
schema_version: "0.1-draft"
character_id: "demo-whale"
name: "大肥鱼"
creator: "community-author"
license: "TBD"
profile:
  background: "角色背景描述"
  personality: ["活泼", "爱游戏", "短句交流"]
  speaking_style: "自然、不过度冗长"
behavior:
  proactive_chat: false
  quiet_hours: "23:00-09:00"
  allowed_channels: ["qq"]
memory:
  policy: "consent_required"
  default_share_scope: "private_only"
plugins:
  optional: ["reminder", "meme"]
assets:
  avatar: null
```

该格式仅用于规划，发布前需确定版本规则、素材权属与导入校验。角色卡不可更改平台安全策略。

## 2. 人格广场故事

- 创作者编辑角色、选择可见性、预览多轮对话、导出或发布。
- 用户搜索、预览、安装角色卡，使用自己的模型和插件配置。
- 支持收藏、Fork、版本更新、反馈与举报。
- 角色卡及广场默认不包含私聊、群历史、私人记忆或 API 配置。
- 角色跨渠道或引擎迁移时不丢失可迁移的角色卡。

## 3. 记忆范围

| 空间 | 可见范围 | 跨端策略 |
|---|---|---|
| 公共角色设定 | 授权角色实例 | 是 |
| 个人长期偏好 | 经身份确认的本人 + 绑定角色 | 用户同意后 |
| 私人会话 | 本人和该角色的特定对话 | 默认不共享到群 |
| 娱乐群记忆 | 仅对应群空间 | 默认否 |
| 工作群资料 | 工作空间的授权成员 | 默认否 |

## 4. 记忆生命周期

候选抽取 → 风险/真实性筛查 → 用户确认或明确指令 → 持久化 → 受控检索 → 纠正、过期或删除。

- 不把模型推测、传闻和敏感个人数据自动提升为永久事实。
- 保留受控来源引用，禁止把群聊原文复制到公开仓库。
- 删除时考虑缓存、检索索引和备份的生存周期。
- 用户能够查看“为什么记住/引用了这件事”。

## 5. 情感安全

- 主动聊天可关闭、调频与设置勿扰。
- 避免排他性诱导、负面情绪操控或夸大 AI 自主意识。
- 情绪理解不等于心理诊断；重大问题不替代专业帮助。
- 未成年人与敏感场景须后续专项评审。
