## 验收记录格式

```text
case_id: A01
date: YYYY-MM-DD
environment: OS / QQ / 接入组件 / Agent / 插件版本
steps: 执行步骤
expected: 预期
actual: 实测
log_ref: 脱敏日志或截图
result: PASS | FAIL | BLOCKED
issue: GitHub Issue 或修复提交
```

## 额外注意

- 若 QQ 账号再次因接入方式被限制，应暂停高风险自动化测试并评估更合规的适配器。
- 旧 QQ-BOT 服务恢复与服务器变更需遵循独立授权边界。
- 公开仓库不得提交有个人标识或真实秘密的日志、截图、消息原文。
