## 历史 QQ-BOT 决策与新平台

- 旧项目“暂不做长期记忆”是当时 2C2G 内存压力下的取舍，不限制新产品。
- 旧项目“不换 SnowLuma”针对当时服务器风控问题，不等同于禁止独立 Windows 原型的技术比较。
- 新仓库不得复制 QQ 登录缓存、真实 QQ 号、聊天原文、Token、Cookie 或公司内部材料。
